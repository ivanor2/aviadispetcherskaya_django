# Система бронирования авиабилетов (Django)

Веб-приложение для управления авиабилетами, написанное на Django с интеграцией внешнего API для аутентификации и управления данными.

## 📋 Описание

Приложение предоставляет функционал для:
- Аутентификации и регистрации пользователей через внешний API
- Поиска и просмотра доступных рейсов
- Управления пассажирами
- Бронирования билетов (включая стыковочные рейсы)
- Ролевой модели доступа (гость, пользователь, администратор)

## 🚀 Быстрый старт

### Требования

- Python 3.8+
- Django 4.x
- Библиотеки: `requests`, `python-decouple`

### Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone <repository-url>
   cd <project-directory>
   ```

2. **Создайте виртуальное окружение:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   # или
   venv\Scripts\activate     # Windows
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения:**
   
   Создайте файл `.env` в корне проекта:
   ```env
   SECRET_KEY=your-secret-key-here
   DEBUG=True
   API_BASE_URL=http://localhost:8001
   ```

5. **Примените миграции:**
   ```bash
   python manage.py migrate
   ```

6. **Запустите сервер разработки:**
   ```bash
   python manage.py runserver
   ```

7. **Откройте браузер:**
   ```
   http://127.0.0.1:8000/
   ```

## 🔐 Аутентификация

Приложение использует внешний API для аутентификации:

- **Login**: `/login/` — вход в систему
- **Register**: `/register/` — регистрация нового пользователя
- **Logout**: `/logout/` — выход из системы

### Роли пользователей

| Роль | Описание |
|------|----------|
| `guest` | Гость (ограниченный доступ) |
| `user` | Обычный пользователь |
| `admin` | Администратор (полный доступ) |

## 📡 API Интеграция

Приложение взаимодействует с внешним API через контроллеры:

- **AuthController** — аутентификация и управление сессиями
- **FlightController** — операции с рейсами
- **PassengerController** — управление пассажирами
- **BookingController** — бронирование билетов

Базовый URL API настраивается через переменную `API_BASE_URL`.

## 🛣️ Основные маршруты

### Рейсы
| URL | Описание |
|-----|----------|
| `/flights/` | Список всех рейсов |
| `/flights/<id>/` | Детали рейса |
| `/flights/create/` | Создание рейса |
| `/flights/search/` | Поиск рейсов |
| `/flights/<id>/delete/` | Удаление рейса |
| `/flights/delete-all/` | Удаление всех рейсов |

### Пассажиры
| URL | Описание |
|-----|----------|
| `/passengers/` | Список пассажиров |
| `/passengers/<id>/` | Детали пассажира |
| `/passengers/create/` | Создание пассажира |
| `/passengers/<id>/delete/` | Удаление пассажира |
| `/passengers/search/` | Поиск пассажиров |

### Бронирования
| URL | Описание |
|-----|----------|
| `/bookings/select/` | Выбор рейса для бронирования |
| `/bookings/create/<flight_id>/` | Создание бронирования |
| `/bookings/cancel/<booking_id>/` | Отмена бронирования |
| `/bookings/<booking_id>/delete/` | Удаление бронирования |
| `/bookings/add-connection/` | Добавление стыковочного рейса |

## ⚙️ Конфигурация

### Настройки в `settings.py`

- **SECRET_KEY** — секретный ключ Django
- **DEBUG** — режим отладки
- **API_BASE_URL** — URL внешнего API
- **SESSION_COOKIE_AGE** — время жизни сессии (по умолчанию 1800 сек)
- **LANGUAGE_CODE** — язык интерфейса (ru-ru)
- **TIME_ZONE** — часовой пояс (Europe/Moscow)

### Middleware

Приложение использует кастомный `AuthMiddleware` для:
- Проверки токена аутентификации при каждом запросе
- Автоматического перенаправления на страницу входа при отсутствии токена
- Обновления данных пользователя из API

## 📁 Модели данных

### Airport (Аэропорт)
- Код аэропорта
- Название
- Город

### Flight (Рейс)
- Номер рейса
- Аэропорт вылета
- Аэропорт прилета
- Дата и время вылета

### Passenger (Пассажир)
- Имя
- Фамилия
- Паспортные данные
- Контактная информация

### Booking (Бронирование)
- Ссылка на рейс
- Ссылка на пассажира
- Статус бронирования
- Дата создания

## 🧪 Тестирование (E2E)

Проект покрыт E2E тестами на базе `pytest` и `selenium`.

### Требования для тестов
1. Установленный браузер Google Chrome.
2. Установленные зависимости (включая `pytest`, `selenium`, `webdriver-manager`).
3. Запущенный FastAPI-бэкенд на порту `8001` (или в соответствии с вашей конфигурацией). База данных бэкенда должна быть доступна, так как тесты автоматически создают/обновляют в ней тестового пользователя.

### Запуск тестов
1. Убедитесь, что FastAPI сервер запущен:
   ```bash
   cd ../aviadispetcherskaya
   uvicorn app.main:app --port 8001
   ```
2. Перейдите в директорию Django-приложения:
   ```bash
   cd ../aviadispetcherskaya_django
   ```
3. Запустите тесты:
   ```bash
   pytest tests -v
   ```

*Примечание:* Тесты работают с открытым окном браузера (headless-режим отключен). Для успешного прохождения всех тестов аккаунт должен иметь права администратора (`admin`), так как некоторые тесты проверяют создание и удаление данных.

### Настройка тестового аккаунта
Тестам требуются учетные данные существующего пользователя с правами администратора. Вы должны предварительно создать такого пользователя в базе данных FastAPI-бэкенда.

Передать эти данные тестам можно через переменные окружения `TEST_USERNAME` и `TEST_PASSWORD`. 
По умолчанию, если переменные не заданы, тесты используют логин `aboba` и пароль `123456q!`.

Пример запуска тестов со своими данными (в Windows PowerShell):
```powershell
$env:TEST_USERNAME="my_admin"
$env:TEST_PASSWORD="MyStrongPassword123!"
pytest tests -v
```
Либо в Linux/Mac:
```bash
TEST_USERNAME=my_admin TEST_PASSWORD=MyStrongPassword123! pytest tests -v
```
